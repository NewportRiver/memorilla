# LITE-008X Semantic Shortcut Analysis

The frozen dataset uses a small familiar vocabulary for A and 35 isolated single-token values for B/C/D. The unfamiliar words are isolated from all W manifest text by normalized-string and morphological-prefix checks; this does not establish that the pretrained model never saw them.

The frozen projection did not meet the six-of-eight threshold in any group. Answer-value-only and entity-only controls were retained separately. Group D also included assignment swaps, relation-swapped evidence, order permutations and two-entity interference. Because textual coverage was zero in every group, these are mechanism diagnostics rather than qualified semantic claims.
