# LITE-008Q scientific limitations

The pilot is a NO-GO for generalized semantic bridge learning. The reduced chain finite-difference gate failed; the full 30-layer bridge VJP was not accepted as numerically qualified for off-manifold bridge outputs. The trained bridge achieved only 3/8 development reversals and did not beat untrained, zero, soft-prompt, or mismatched controls. Embedding norms grew far beyond the decoder EOS scale.

Q4 corrected transfer reached only 2/4 reversals. Q4 likelihoods are reported as independent single-token scores, but Q4 semantic-memory qualification is not passed. Ordinary textual evidence, multi-token candidate continuation, query/evidence paraphrase strata, and individually optimized development oracles were not run; no development embedding was optimized.

This does not invalidate LITE-008P isolated FP32 feasibility and does not establish Gates D, E or F.
