# LITE-008X-R1 corrective solutions

New addendum; [decision](LITE-008X-R1-GO-NOGO-DECISION.md). Scientific acceptance remains blocked.

## Implemented engineering boundary

`experiments/lite008x_r1_immutable.py` is a deliberately isolated **JSON float32 reference projection evaluator**, not a decoder or a historical PT adapter. It accepts an independently supplied expected artifact SHA and expected shape; validates float32 declaration, bounded shape, finite numeric content and input length; checks complete encoder/decoder directory inventories against caller-supplied expected file maps and settings; rejects omitted/extra/changed files and symlinks; binds exact query/evidence/candidates/tokens/direction/partition/entity/manifest/model/generation identity to the expected input hash. It computes only `eos + W*x`, emits input/projection/output hashes and rechecks artifact/model bytes before returning. It never imports training/solver modules. The arithmetic is Python accumulation rounded to float32 output, **not bitwise Torch FP32 parity**.

Trust boundary: the caller must provide an independently reviewed, immutable expected inventory and configuration; an attacker-controlled expected hash is not verification. Directory completeness proves included files, not that arbitrary settings accurately describe a decoder. This code does not certify provenance absent from historical artifacts. JSON parse/IO errors fail closed; no output is returned after a failed check. Pre/post hashing does not protect against an adversary modifying and restoring files between checks. The test-only `_after_load` hook injects mutations; no scorer callbacks are accepted.

`tests/lite/test_lite008x_r1_immutable.py`: 15 new tests cover valid/repeated output, missing/wrong SHA, wrong dtype/shape, NaN/infinity/overflow, changed input, incomplete identity, artifact/model mismatch, weight changes, extra shard, post-load projection/model mutation, same-case changed content and symlink. Together with selected existing X/identity/control tests, pytest printed 29 passed. Supervisor status remains failed; see preserved verification records. Real frozen PT execution is **not implemented/certified** under this contract because identity reconciliation and resource qualification are blocked. Do not describe this adapter as full decoder evaluation.
